# 产品需求文档（PRD）：照片转风格生成小程序

> 文档类型：产品需求文档（面向产品经理 / 设计 / 研发）
> 版本：v2.0（微信小程序版）　|　最后更新：2026-10-10
> 平台：**微信小程序（个人主体）**，不做网页版 / Landing Page。
> 一句话定位：**把日常照片一键变成你选定的艺术风格！吉卜力是我们主推的默认风格，此外还支持 Q 版、水彩、像素等 20+ 种风格——具体风格，由你决定。**

---

## 1. 产品概述

### 1.1 产品定位
一款**微信小程序端的 AI 照片转风格生成工具**。用户无需任何绘画或设计基础，从微信相册选择或拍摄照片，由云端 AI 根据所选风格重新绘制，还原柔和色彩与灵动光影，同时保留原图人物、物体、宠物的辨识特征。

**吉卜力是平台主推的默认风格**（作为首屏推荐与默认选中项），但用户可在风格库中自由选择 Q 版、手办、像素画、水彩、漫画等 **20+ 种艺术风格**，具体使用哪种风格**由用户自行决定**，形成一站式的 AI 图片风格化平台。

### 1.2 用户价值主张
| 维度 | 价值点 |
|------|--------|
| 效果价值 | AI **重绘整图**（非简单叠加滤镜），精准复刻所选风格的色彩与笔触（默认吉卜力柔和色彩、手绘天空与灵动角色），保留主体辨识度。 |
| 效率价值 | 上传后约 **20–60 秒**（产品口径统一为「约 1 分钟」）出图；标清下载免费、无水印。 |
| 易用价值 | 四步闭环：**上传 → 选风格 → 生成 → 下载 / 分享**，直接进入微信相册选图或拍照，无需跨端。 |
| 权益价值 | 新用户赠 **1 次免费生成**；生成失败不扣次数；高清 / 更多次数按需付费购买。 |
| 情感价值 | 将日常记忆（宠物、家庭、旅行）变为「魔法回忆」，适合礼物、头像、朋友圈分享。 |

### 1.3 目标人群
- **普通用户**：制作社交头像、纪念图片、礼物装裱。
- **创作者**：设计师、自媒体 / 营销人员获取创意素材。

## 2. 核心功能

### 2.1 照片一键风格迁移
- 从微信相册选择或拍摄照片，由 AI 根据所选风格重新绘制（默认吉卜力），**保留原图人物、物体特征**。
- 支持题材：人像、家庭合照、情侣照、宠物、风景、城市、静物、咖啡馆场景等。

### 2.2 多用途生成
- 生成社交头像、壁纸；
- 家庭 / 旅行照片转为动画感插画；
- 宠物照片做成手绘肖像；
- 成品可保存至相册、分享微信好友 / 朋友圈、打印装裱送礼。

### 2.3 多种艺术风格
- 支持 **吉卜力（主推默认）及 Q 版、手办、像素画、水彩、漫画等 20+ 种风格**；使用哪种风格由用户决定（v1 先上线吉卜力 + 少量验证风格，其余列入路线图）。

---

## 3. 用户使用流程

小程序内四步闭环，v1 即带付费墙：

1. **上传照片** —— 从微信相册选择或拍照（`wx.chooseMedia`）。
2. **选择风格滤镜** —— 从风格库挑选（吉卜力为默认主推，用户可自由切换其他风格）。
3. **生成并付费** —— 免费额度内直接生成；超出后引导购买「次数包」（微信支付），生成约 1 分钟。
4. **下载 / 分享** —— 标清免费保存，高清需次数权益；一键分享微信好友 / 朋友圈（带前后对比卡片）。

> 付费墙规则：**新用户赠送 1 次免费生成**；标清下载免费、无水印；**生成失败不扣次数**。

## 4. UX 设计说明（Design Spec · 微信小程序原生）

> 参考站点：[吉卜力风格（ghiblistyle.co/zh）](https://ghiblistyle.co/zh) 的文案与视觉基调（作为默认风格的参考样例）；交互形态按微信小程序规范重做。
> 设计目标：用「奇幻 + 温馨」的童话感（默认吉卜力风格的基调）降低技术认知门槛，让用户感觉自己在进行一场「魔法创作」；整体视觉与文案可随用户所选风格延展。

### 4.1 文案与语气规范（Tone & Voice）
- **语言调性**：简体中文，亲切活泼、富有感染力与幻想色彩；高频使用「魔力」「梦幻」「神奇」「温馨」「奇幻」等词，默认以吉卜力风格的童话感作为主视觉基调，并随用户所选风格延展。
- **句式特征**：短句为主，多用感叹号点缀；大量使用引导性祈使句（如「上传照片」「试试吉卜力滤镜 →」）。
- **用户视角**：强调「零基础」「一键」「无需设计技能」，把技术能力转译为用户可感知的益处。
- **叙事结构**：小程序按「首页 → 风格 → 生成中 → 结果」的页面栈推进，首页承载「是什么 / 为什么 / 示例 / 定价入口」，并配 FAQ 弹层降低认知门槛。

**推荐主标题 / 副标题文案（可直接采用）：**
- H1：**把日常照片，变成你想要的艺术风格！**
- Sub：**吉卜力是我们主推的默认风格——你也能一键切换到 Q 版、水彩、像素等 20+ 种风格，具体由你决定。**

### 4.2 小程序页面结构（非单页 Landing）
| 页面 / 组件 | 内容要点 |
|------|----------|
| 底部 TabBar | 「创作」（首页）、「我的」（次数 / 订单 / 客服）。 |
| 首页（创作） | 主标题 + 副标题 + 上传入口（「从相册选择 / 拍照」双按钮）+ 示例画廊（前/后对比）+「尝试以下示例」。 |
| 风格选择页 | 风格网格（吉卜力作为主推默认置于首位并高亮 + 其余 20+ 风格标签），点击即预览示意，可自由切换。 |
| 生成中页 | 进度态：「正在为您的照片注入魔力…」+ 魔法感动画，约 1 分钟，可后台。 |
| 结果页 | 前/后对比滑块 + 「保存至相册（标清免费 / 高清权益）」+「分享给好友 / 朋友圈」。 |
| 付费弹层 | 次数包卡片（免费 1 次提示 / 体验包 / 超值包），微信支付拉起。 |
| 我的页 | 剩余次数、购买记录、常见问题（FAQ 弹层）、客服入口、免责声明入口。 |

> 说明：小程序无自由 URL 锚点，原网页的「#pricing 锚点 / 单页滚动」改为底部 TabBar + 页面栈 + 弹层。

### 4.3 色彩与视觉基调（Design Tokens）
按「柔和色彩、梦幻光影、温馨绘本质感」定义设计变量，模拟吉卜力手绘质感；**避免高对比刺眼色**。

| Token | 推荐取值 | 用途 |
|-------|----------|------|
| `--color-primary` | 自然绿（如 `#7BA05B`） | 主按钮、强调 |
| `--color-secondary` | 天蓝（如 `#8EC5E8`） | 辅助、链接 |
| `--color-bg` | 暖米色（如 `#FBF6EC`） | 页面背景 |
| `--color-text` | 深暖灰（如 `#3A3A3A`） | 正文 |
| 饱和度 / 明度 | 低饱和、高明度 | 整体画面柔和不刺眼 |

> 建议沉淀为一套全局 Design Tokens（色彩 / 圆角 / 间距 / 字号），保证全站一致性。

### 4.4 按钮与 CTA（行动号召）
- **主按钮**：「从相册选择」「拍照」「免费开始」「购买次数包」。
- **行内引导按钮**：箭头引导（「试试吉卜力滤镜 →」「查看次数包 →」「生成 Q 版头像 →」）。
- **零风险文案**：强调「新用户免费 1 次」「生成失败不扣次数」「一次性付款，不自动续费（订阅除外）」，降低付费顾虑。

### 4.5 微文案（Microcopy）
- 上传区：**「从相册选择 或 拍照上传」**
- 步骤引导：**「1 选择照片　2 挑选风格（默认吉卜力）　3 等待魔法生成　4 保存或分享」**
- 空状态 / 示例：**「尝试以下示例」**
- 处理中：**「正在为您的照片注入魔力…」**（魔法感状态提示）
- 次数耗尽：**「免费次数已用完，购买次数包继续创作 →」**

### 4.6 对比展示（Before-After）
- 结果页用「前 / 后对比滑块」直观呈现原图与转换图，**降低用户决策与分享传播成本**。
- 首页示例画廊直接展示「原图 → 转换后」样例，第一眼建立效果信任。

### 4.7 风格分类标签体系（Taxonomy）
- **主题维度**：人像、宠物、家庭、风景、场景（咖啡厅）、静物、情侣、自然、猫咪、城市、幻想、海滩。
- **风格维度**：吉卜力（默认主推）、Q 版（chibi）、手办公仔、3D 收藏手办、像素画、水彩画像、黑白漫画等 **20+**，具体由用户选择。

### 4.8 分享与传播（微信原生）
- 结果页一键「分享给好友 / 分享到朋友圈」，分享卡片带前后对比缩略图 + 小程序码，形成获客闭环。
- 可设计「生成后分享得免费次数」的裂变钩子（v1 后可做，需评估微信诱导分享合规）。

### 4.9 空状态与引导
- 首次进入或无历史记录时，展示示例画廊 +「尝试以下示例」，避免空白焦虑。
- 生成失败后，明确提示「本次未扣次数，请重试」，强化信任与安全感。

## 7. 技术约束与生成服务抽象

- **生成后端可插拔**：v1 不绑定具体模型厂商，定义统一的「生成服务」抽象接口（输入：原图 + 风格参数；输出：生成图 / 状态 / 耗时），后续可接入 **QWEN、seedream** 等任一图像生成服务，UX 与计费层不感知厂商差异。
- **成本与稳定性未知**：因生成后端未定，单张成本、并发、失败率上线前需压测；付费墙须与「失败不扣次数」「生成超时兜底」强绑定，避免亏在生成失败。
- **小程序原生能力**：上传用 `wx.chooseMedia`、保存用 `wx.saveImageToPhotosAlbum`、分享用 `onShareAppMessage` / `onShareTimeline`、支付用微信支付（虚拟支付 / 小程序支付）。
